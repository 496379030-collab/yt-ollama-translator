YouTube Realtime English Video Translator

这是一个专为 YouTube 设计的实时中英双语字幕翻译插件。它通过调用你本地运行的 Ollama AI 模型，将英文视频字幕瞬间转化为地道的中文，且完全免费、保护隐私。

🌟 核心亮点

电影级观感：采用纯白字体配合柔和的黑色阴影，无背景遮挡，字幕显示更自然。

强力失效保护：内置严密的上下文检查机制（Context Invalidated Protection），即便是刷新插件或重载环境，也不会导致页面卡顿或报错。

极速响应：采用了语段切割与延时触发逻辑，确保翻译既快又准。

完全本地运行：不经过任何云端 API，无需担心隐私泄露，也不产生任何订阅费用。

🧠 技术原理 (FAQ)

Q：它是如何提取字幕的？是靠 OCR 图像识别吗？
A： 不是。插件通过 MutationObserver 技术实时监听 YouTube 播放器的 DOM 变化，直接抓取渲染在页面上的 CC (Closed Captions) 文本。这种方式比 OCR 更快、更准，且占用资源极低。

Q：它能翻译视频画面里的“硬字幕”吗？
A： 目前不能。因为它依赖于 YouTube 的 CC 功能。只要视频开启了原声 CC 字幕（哪怕是自动生成的），插件就能正常工作。

🛠️ 快速安装指南

1. 准备“翻译大脑” (Ollama)

首先，从 Ollama 官网 下载并安装。

打开终端，运行以下命令下载推荐的轻量级模型：

ollama pull qwen2.5-coder:7b


2. 以“跨域许可”模式启动 Ollama (关键)

为了让浏览器插件能顺利访问本地 AI 服务，请先彻底退出菜单栏的 Ollama 图标，然后在终端输入：

OLLAMA_ORIGINS="*" ollama serve


3. 安装插件到浏览器

将本项目的所有代码下载/克隆到本地。

在 Chrome 地址栏输入 chrome://extensions/。

开启右上角的“开发者模式”。

点击“加载已解压的扩展程序”，选择本项目所在的文件夹。

📺 如何使用？

打开任意 YouTube 英文视频。

务必点击视频右下角的 "CC" 图标开启英文原声字幕。

插件会自动拦截这些字幕并将其发送给 Ollama 进行翻译。

稍等片刻，精美的双语字幕就会出现在视频底部！
